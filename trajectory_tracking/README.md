# Trajectory Tracking Test Generation

This module provides utilities for generating trajectory tracking test cases
 to be consumed by the
[Aurora](https://github.com/tiiuae/Aurora) simulation test framework,
which performs the actual simulation execution and trajectory tracking evaluation.

This module does **not** implement:
- trajectory tracking controllers
- flight control algorithms
- simulation environments
- trajectory tracking evaluation

Instead, it provides a bridge between this project and external [Aurora](https://github.com/tiiuae/Aurora) testing
framework.

---

## Purpose

The trajectory generation and planning tools in this repository produce
reference trajectories. These trajectories can be evaluated using external
trajectory tracking frameworks.

This module automates the preparation of the required test configuration files:

- trajectory input files
- trajectory publisher configurations
- ground truth recorder configurations
- test definitions
- framework configuration files

The generated files can then be executed externally to produce tracking results by following instructions in [Aurora](https://github.com/tiiuae/Aurora) repo.

## Workflow

The typical workflow is:

```
Trajectory Generation
        |
        v
Trajectory CSV Files
        |
        v
trajectory_tracking/
(generate test configurations)
        |
        v
Aurora Framework
(simulation + trajectory tracking)
        |
        v
Tracking Results
        |
        v
analysis/
(metrics, plots, reports)
```

## Generated Directory Structure

Given an input directory containing trajectories:

```
input/
├── scenario_1/
│   └── trajectory.csv
└── scenario_2/
    └── trajectory.csv
```

the generator creates:

```
output/
├── config/
│   ├── config_x500.json
│   │
│   ├── trajectory/
│   │   ├── scenario_1/
│   │   │   └── trajectory.json
│   │   └── scenario_2/
│   │       └── trajectory.json
│   │
│   └── io/
│       ├── scenario_1/
│       │   └── gz_ground_truth_recorder.json
│       └── scenario_2/
│           └── gz_ground_truth_recorder.json
│
├── test/
│   ├── scenario_1/
│   │   └── test.json
│   └── scenario_2/
│       └── test.json
│
└── results/
    ├── scenario_1/
    └── scenario_2/
```

## Usage

Run:

```bash
python generate_aurora_tests.py \
    --input <trajectory_directory> \
    --output <output_directory>
```

Example:

```bash
python generate_aurora_tests.py \
    --input ../results/trajectories \
    --output ../aurora_tests
```

---

## Docker / Container Support

When the generated configuration files are executed inside a container (as is the case with Aurora),
paths can be converted automatically using:

```bash
--container-root <container_mount_path>
```

Example:

```bash
python generate_aurora_tests.py \
    --input results \
    --output aurora_tests \
    --container-root /workspace/external
```

The generated JSON files will contain container-compatible paths.

---

## Input Requirements

The generator expects trajectory files named:

```
trajectory.csv
```

with the trajectory data generated by this project.

Each trajectory file is converted into a trajectory publisher configuration
that can be consumed by the external tracking framework.

## Limitations

This module only prepares test cases.

Actual trajectory tracking execution requires the external Aurora framework
and its associated simulation environment.
